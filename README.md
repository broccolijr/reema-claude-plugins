# REEMA の Claude Code 道具箱

小さなお店・会社・ひとり事業の人のための、Claude Code の無料プラグインです。

## 返信の温度(henshin-ondo)

お客さんへの返信、LINE、DM、メール。送る前に「強すぎない？」「へりくだりすぎ？」と迷う短い文を、そのまま貼れる形に整えます。

- へりくだりすぎない
- 盛らない(できない約束・感じていない気持ちを書かない)
- 相手に不安を先に渡さない
- 締めの「次に動くのは誰か」を取り違えない

### 使う前 → 使った後

> 一度お話しできませんか？準備ができたらお気軽にご連絡ください！

> 一度15分ほどお話ししませんか？
>
> 準備ができたら、こちらからご連絡しますね。

### 入れ方

Claude Code の中で、次の2行を順に打ちます。

```
/plugin marketplace add broccolijr/reema-claude-plugins
/plugin install henshin-ondo@reema
```

あとは「この返信を整えて」と文を貼るだけです。送信はしません。送るのはあなたです。

## English

A free Claude Code plugin that adjusts the tone of short Japanese business messages (replies, LINE, DMs, emails) for small businesses: not too humble, no overpromising, no planting worries.

```
/plugin marketplace add broccolijr/reema-claude-plugins
/plugin install henshin-ondo@reema
```
