# 出す前の検査(8項目)

1. 立場は合っているか(出す側なのに遠慮していないか/お願いする側なのに命令していないか)
2. 「〜させていただきます」が2回以上出ていないか(1回まで)
3. 言い切りの約束(必ず・絶対・〜してみせます)が無いか
4. 相手の頭にまだ無い不安を名指ししていないか(揉める・トラブル・後から言った言わない)
5. 逃げ道の文が2つ以上重なっていないか(1つまで)
6. 最後の1文の「動く人」は合っているか
7. 分からない事実を作っていないか(日付・金額・したこと・感じたこと)
8. 「？」「！」は全角か。スマホ向けなら、かたまりごとに空行があるか

引っかかった項目は、直した結果と一緒に「何番を直したか」を書く。
