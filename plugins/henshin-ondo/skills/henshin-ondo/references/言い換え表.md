# 言い換え表(元 → 直し・理由)

| 元 | 直し | 理由 |
|---|---|---|
| ご検討いただけましたら幸いでございます | ご検討いただけるとうれしいです | へりくだりすぎ。対等に |
| 精一杯がんばらせていただきます | 〇〇の部分は得意なので、お役に立てると思います | 意気込みでなく中身で |
| 必ずご満足いただける仕上がりにします | 前回の〇〇と同じ流れで進めます | 約束を盛らない |
| 後で認識のずれが起きないよう、念のため確認です | 〇〇は△△で進めますね | 不安を先に渡さない |
| 明日までにお返事ください | 明日中にお返事をいただけると、金曜の納品に間に合います | 宣言を、相手の得の理由に |
| 一度お話しできませんか？ | 一度15分ほどお話ししませんか？ | お願いでなく誘い |
| 準備ができたらお気軽にご連絡ください(準備するのはこちら) | 準備ができたら、こちらからご連絡しますね | 動く人の取り違え |
| 何かあればいつでも対応します！土日もOKです！ | ふだんは当日中にお返事しています | がんばりでなく結果で |
| データが必要でしたらお知らせください | 元データは手元に残すので、縦長への作り替えもすぐできます | 「念のため欲しい」を生まない |
| 経験が少なく不安もありますが | 〇〇の経験は2年です。特に大事にされている点を伺えますか？ | 告白でなく質問に |
